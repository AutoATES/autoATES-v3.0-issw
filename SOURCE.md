# Provenance

This repository is a **public snapshot** of the autoATES v3.0 library for
the ISSW 2026 workshop. It is not the development tree.

| | |
|---|---|
| Private development repo | `AutoATES/AutoATES-v3.0` (not public) |
| Snapshot of | commit `adb83f616576` (16 September 2026) |
| Default settings | ISSW 2026 / western Canada production stack |
| Workshop notebooks + Connaught data | `AutoATES/issw2026-autoates-workshop` |

Site-batch configs, calibration sweeps, and unpublished experiments were
left out on purpose. Parameters here are the ISSW working version
(typical + infrequent PRA, ruggedness off, Flow-Py α 30° / 18°).
The snapshot of `adb83f6` left dev8 off the pipeline call. This tree runs it.
